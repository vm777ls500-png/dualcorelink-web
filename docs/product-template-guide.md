The source checklist is `product-content-templates.json`. It uses the existing
WordPress `product` CPT and confirmed ACF field names. It does not create posts.

## Required Content

- WordPress title, excerpt, and product overview
- Verified model and short description
- Approved product images
- Electrical, wireless, environmental, and dimensional specifications
- MOQ, lead time, warranty, sample, OEM, ODM, and private-label status
- Related solutions, FAQs, certifications, and controlled downloads
- SEO, GEO, and Schema review

Do not infer prices, certifications, manufacturer status, performance claims,
or compatibility data. Use verified supplier documentation.
