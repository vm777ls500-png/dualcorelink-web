# SEO Growth Phase 2D — Resource Topic Cluster Expansion

## Scope

This phase added four new English Resource articles to expand the hotel room control SEO topic cluster. The implementation reused the existing static Resource configuration, shared detail route, Phase 2C conversion components, schema builders, and sitemap collection logic.

No WordPress content, product data, Solution content, Region content, FAQ procurement terms, language routing, Cloudflare configuration, environment variables, DNS, `wrangler.toml`, or dependencies were changed.

## New Resource Pages

- `/en/resources/hotel-rcu-wiring-system-architecture-guide/`
- `/en/resources/hotel-room-control-system-cost-factors/`
- `/en/resources/hotel-occupancy-sensor-selection-guide/`
- `/en/resources/hotel-doorplate-room-display-buying-guide/`

## Content Coverage

- RCU wiring, room-control architecture, strong-current and weak-current boundaries, device relationships, integration planning, and engineering handoff information.
- Hotel room control system cost factors, quotation scope, hardware and service categories, customization, hidden cost risks, and comparison inputs without publishing prices.
- Occupancy and presence sensor technologies, area-specific selection logic, RCU integration, privacy, false-trigger considerations, and representative-room testing.
- Doorplate, room-number display, doorbell, configurable DND/MUR logic, mounting, maintenance, OEM/ODM appearance options, and procurement inputs.

Each new guide contains at least nine H2 sections, reusable H3 subsections, buyer-focused project guidance, verified internal references, and more than 1,000 English content words. Electrical and sensor content avoids field installation instructions, unverified protocol support, unsupported ratings, fixed pricing, ROI claims, and guaranteed performance.

## Conversion Integration

All four pages reuse `src/components/content/resource-conversion-sections.tsx` and the central mappings in `src/config/resources.ts` for:

- Mid-article project consultation CTA.
- Recommended Products.
- Relevant Solutions.
- Continue Reading.
- Final Project Inquiry CTA.
- Contact, inquiry, downloads, and WhatsApp paths.

The detail template received a small shared extension for optional H3 subsections and contextual in-article Resource links. No article-specific JSX pages or duplicate conversion components were created.

## Internal-Link Expansion

The five Phase 2A guides now link into the new cluster through their existing Continue Reading mappings:

- Hotel RCU Buying Guide → RCU Wiring Guide.
- Smart Hotel Room Control System Guide → RCU Wiring Guide and Cost Factors Guide.
- Hotel Guest Room Automation Guide → Occupancy Sensor Guide and Doorplate Buying Guide.
- Hotel Smart Switch Panel Guide → Doorplate Buying Guide.
- OEM/ODM Smart Panel Customization Guide → Doorplate Buying Guide.

The four new guides use distinct recommendation sets. They connect back to the relevant RCU buying, room control, guest room automation, smart panel, and OEM/ODM guides. The Cost Factors Guide links to OEM/ODM customization, the Doorplate Guide links to the Smart Switch Panel Guide, and the Occupancy Sensor Guide links to Guest Room Automation.

## SEO and Schema

- Four unique slugs, titles, descriptions, canonical URLs, Open Graph metadata, and Twitter metadata were added.
- Article JSON-LD and BreadcrumbList JSON-LD are generated by the existing shared detail route.
- All four new URLs are included automatically in the Resources list, CollectionPage/ItemList data, static params, and sitemap.
- Sitemap increased from 67 to 71 URLs.
- Existing Product schema policy was retained: no offers, public price, availability, review, or aggregate rating was added.

The task baseline described five existing Resource pages and an expected nine-page total. The repository actually contained six public Resource detail pages before Phase 2D: five Phase 2A guides plus the earlier RCU pilot guide. The correct post-change result is therefore ten public Resource detail pages. Nine topic-cluster pages use the Phase 2C conversion system, while the early pilot remains published. Removing that valid page would have broken the established 67 → 71 sitemap requirement.
