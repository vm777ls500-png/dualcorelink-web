# Product Assets Intake

This directory is the intake area for DUALCORE LINK product source materials.

## Directory Usage

- `raw-images/`: Store all original product images.
- `raw-documents/`: Store product introduction documents, TXT, DOC, PDF, Markdown, spreadsheets, and related source notes.
- `application-scenarios/`: Store application scenario images. These are not product images and should not be treated as product category assets.
- `mapping-output/`: Store generated product asset package mapping tables.

## Important

Product images and documents on the user's local computer must be copied into these directories before Codex can rescan the project and generate a formal product asset package mapping table.

Keep original file names when possible. Do not mix application scenario images into `raw-images/`.
